# Public previews and card sharing

2026-10-17 production update.

Publicly listed works with previews enabled can now be previewed without authentication, including separate preview assets and bounded text-preview streams. Unlisted/removed/preview-disabled works and unattached preview drafts remain unavailable to visitors. The original media, download and preview-editor routes retain their existing access controls. Both the play-page login redirect and preview API login checks were corrected. A visitor requesting play without an explicit preview flag receives only the public sample.

Preview reads return private, no-store plus no-cache/expiry and noindex/nofollow/noarchive headers. The app fetches preview data with cache:no-store. Preview playback does not restore or submit account progress, does not display save-to-library controls and does not activate playlists. The server rejects preview-only users' progress writes and explicit preview-mode writes, including owners' preview sessions. Historical progress for works without full access is excluded from account snapshots. No old database rows are deleted. These controls prevent application persistence and caching; publicly displayed bytes cannot be guaranteed impossible to copy or capture.

The share dialog is portalled to document.body and stops click propagation. This fixes the mobile card's broad button selector affecting buttons inside the dialog. Both card actions use consistent 36 px buttons, 18 px SVGs, border radii, alignment and selection colors. Dialog copy/native buttons have separate touch sizes. When available, native sharing is invoked directly from the initial user click before asynchronous work. Clipboard copying attempts synchronous selected-input copying, then the Clipboard API with a 1500 ms deadline, immediate status feedback and a visible selectable URL if unavailable. All six social channel links/icons remain. A native dialog fallback is retained for browsers lacking showModal.

Validation: 57 focused public-access/cache/history checks, 36 share/reader/icon checks, 124 independent-preview regressions, 78 original-file/comment-policy checks, 44 preview-entry checks and 52 attachment/metadata checks pass. All mutations were tested on synthetic local databases. Live anonymous HTTP confirms preview:true with no-store/noarchive headers. The published app/CSS bytes match validation. Live browser confirms body-level portal placement, no dialog inside cards, equal button dimensions/alignment, the play preview with image-count progress, and copy UI success feedback. The cloud browser's clipboard readback was empty despite copy-command acceptance, so actual device clipboard contents are not verified. No external share was sent. Native OS sharing and physical mobile layout were not exercised; their platform support cannot be added by this release.
