# 星页

一个类似创作者社区的演示站点：浏览创作者、阅读动态、购买数字作品，并用 30 天会员解锁会员内容。会员不会自动续费，结账不会产生真实扣款。

## 本地运行

```bash
npm install
npm run dev
```

浏览器打开 http://localhost:5173
